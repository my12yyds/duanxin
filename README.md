# 短信卫士 · Message Guard

短信卫士是一个中文、本地运行的通知合规演示工作台。它用虚构资料演示如何管理订阅同意、通知模板、退订抑制、频率限制和审计记录，适合产品原型、教学和规则评审。

> **演示版说明：** 当前版本不会发送短信，不连接短信服务商或后端，也不会收集真实手机号。请只使用虚构资料。所有工作区数据保存在当前浏览器的本地存储中。

## 快速开始

### 在线使用

合并到 `main` 并完成 GitHub Pages 部署后，可从仓库首页的 **Deployments** 或 Pages 地址打开工作台。首次发布前，请在仓库的 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。

### 在本机预览

1. 下载或克隆本仓库。
2. 直接打开 `public/index.html`，或用任意静态文件服务器托管 `public/` 目录。
3. 页面加载后会自动创建虚构的示例工作区，可从左侧导航体验各模块。

项目不需要安装依赖、配置密钥或构建前端资源。

## 功能

- **工作台总览：** 汇总联系人、同意、退订、活动演练和当前保护规则。
- **联系人与同意：** 添加、编辑和删除虚构联系人；记录同意状态及变更时间。
- **通知模板：** 新建、编辑、搜索、删除和预览模板，支持 `{name}` 等占位符。
- **活动演练：** 按当前规则计算本地资格，展示符合条件与排除原因；演练只生成本地记录，不创建发送任务。
- **退订抑制：** 退订联系人会从后续资格结果中排除。重新启用需要明确确认已有新的用户同意。
- **频率与安静时段：** 设置每位联系人每日演练上限以及安静时段，检查跨午夜时段和达到频率上限的情况。
- **操作审计：** 在浏览器本地查看工作区变更和演练记录，最多保留最近 250 条。
- **数据管理：** 导出 JSON 备份或恢复初始虚构数据。
- **响应式与键盘支持：** 支持窄屏导航、跳到主内容、语义化表单、状态提示和键盘操作。

## 数据与隐私

应用使用浏览器 `localStorage` 保存当前工作区。数据不会自动同步到其他设备或上传到本仓库。清除浏览器站点数据会删除本地工作区；需要保留时，请先在“规则与数据”中导出 JSON 备份。

演示页面没有账户登录或多用户权限隔离，因此不要输入真实手机号、客户资料、验证码、访问令牌或其他敏感信息。导出的 JSON 也应按本机文件妥善保管。

## 发布到 GitHub Pages

仓库内的 `.github/workflows/static.yml` 会把 `public/` 发布到 GitHub Pages：

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
3. 将更新合并到 `main`；在 **Actions** 页面查看 “Deploy static site to GitHub Pages” 工作流。
4. 等待部署成功后，从 Pages 页面给出的地址访问。

`.github/workflows/validate.yml` 会在 Pull Request 和推送到 `main` 时检查 JavaScript 语法及 Pages 必需文件。Dependabot 每月检查 GitHub Actions 版本更新。

## 项目边界

本项目用于演示合规通知的产品流程，不接受短信轰炸、骚扰、规避退订或触达未授权对象的能力。若未来建设合法的真实通知服务，必须另行设计服务端授权校验、实时退订抑制、频率控制、凭据管理和审计流程，并遵守适用法律及服务商规则。
