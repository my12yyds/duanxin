# 短信卫士 · Message Guard

一个帮助开发者设计合规、尊重用户选择的短信通知服务的中文指南与交互式检查清单。

当前版本是纯静态演示：不发送短信、不连接短信服务商、不收集手机号。勾选清单只保存在当前浏览器，不会上传。

## 项目内容

- **同意管理**：在联系用户前记录明确、可撤回的订阅同意。
- **退订流程**：让用户能用清晰、简单的方式停止通知，并及时生效。
- **发送治理**：为通知设置用途、频率、发送时段和速率上限。
- **隐私最小化**：只保存必要信息，限制访问并设定删除期限。
- **安全留痕**：记录授权、退订和异常处置，便于排查误发。
- **本地检查清单**：逐项检查上线准备情况，数据仅保存在浏览器本地。

## 本地预览

直接打开 `public/index.html` 即可预览。页面不依赖构建工具或第三方脚本。

## GitHub Pages

仓库使用 GitHub Actions 部署 `public/` 目录。推送到 `main` 后会触发部署，也可以在 Actions 页面手动运行。请在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。

## 开发原则

任何真实短信集成都必须先满足明确授权、可撤回同意、有效退订、发送频率限制、最小化数据保存和事件审计。不得将本项目用于骚扰、轰炸、绕过平台限制或向未经同意的对象发送消息。

安全问题请阅读 [SECURITY.md](SECURITY.md)。欢迎贡献请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。
