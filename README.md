# 短信卫士 · Message Guard

一个帮助开发者设计合规、尊重用户选择的短信通知服务的中文本地演示工作台。

当前版本是纯静态演示：不发送短信、不连接短信服务商、不收集真实手机号。工作区数据只保存在当前浏览器，不会上传。

## 当前功能

- **工作台总览**：查看联系人、授权、退订和演练概况。
- **联系人与授权**：添加虚构联系人，记录授权状态和重新授权时间。
- **模板管理**：创建、编辑、删除和预览服务通知文案。
- **活动演练**：只对已授权联系人做本地资格检查，不会建立发送任务。
- **退订抑制**：将退订联系人从演练资格中排除；重新订阅必须确认新的明确同意。
- **频率与安静时段**：配置每日演练次数上限和安静时段，并应用于演练结果。
- **操作审计**：查看本地变更记录，最多保存最近 250 条。
- **数据管理**：导出 JSON 备份或恢复虚构的初始示例数据。

## 本地预览

直接打开 `public/index.html` 即可预览。页面不依赖构建工具或第三方脚本。

## GitHub Pages

仓库使用 GitHub Actions 部署 `public/` 目录。推送到 `main` 后会触发部署，也可以在 Actions 页面手动运行。请在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。

## 开发原则

当前工作台没有真实短信集成。未来若为合法服务提醒添加服务端能力，必须只对明确订阅用户发送，实时尊重退订，设置频率与安静时段限制，安全保管凭据，并记录必要的授权和处置审计。不得用于骚扰、轰炸、绕过平台限制或向未经同意的对象发送消息。

安全问题请阅读 [SECURITY.md](SECURITY.md)。欢迎贡献请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。
